## 🐛 Utfordringer løst

### 1. Slug route konflikter
**Problem:** `/{slug}` route fanget alle routes  
**Løsning:** Plasserte slug routes sist i web.php
- Public booking routes plassert etter alle andre routes
- Sikrer at `/dashboard`, `/admin`, etc. ikke fanges av slug

### 2. Alpine.js state management i components
**Problem:** Hvordan dele state mellom trigger og modal  
**Løsning:** Brukte `x-data="{ open: false }"` på wrapper
- State deles automatisk mellom alle child elements
- `@click="open = true"` på trigger
- `x-show="open"` på modal content

### 3. Tenant-isolasjon i policies
**Problem:** Bookinger tilhører ressurser, ikke direkte til tenant  
**Løsning:** Sjekket via relationship
- `$booking->resource->tenant_id === $user->tenant_id`
- Eager loading av resource for å unngå N+1
- Samme pattern for alle booking-relaterte policies

### 4. Filter og søk kombinasjon
**Problem:** Hvordan kombinere søk og filter i Alpine.js  
**Løsning:** Computed property `filteredCount`
- Teller synlige tenants basert på begge kriterier
- AND-logikk: Begge må være oppfylt
- Viser "No results" når count === 0
